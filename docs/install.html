Install

Rust

cargo add hikari-rs
# just the pieces you need:
cargo add hikari-rs-core hikari-rs-pdf

Node.js

npm i @hikari-rs/node
node -e "const hk = require('@hikari-rs/node');
const png = hk.renderPngSync(JSON.stringify(tree), 1200, 630);"

Prebuilt for macOS, Linux (glibc + musl) and Windows on x64 + ARM64. Pro PDF reads HIKARI_LICENSE / HIKARI_PUBKEY from the environment.

Browser / edge workers

import init, { render_png } from './playground/pkg/hikari_wasm.js';
await init();
const pngBytes = render_png(JSON.stringify(tree), 1200, 630); // Uint8Array

From source

git clone https://github.com/theoxfaber/hikari && cd hikari
cargo test --workspace          # 60+ tests
cargo run -p hikari-rs --example card
node npm/test.mjs               # needs npm/hikari-node.node built (see below)

Build the Node binding locally

cargo build -p hikari-rs-node
cp target/debug/libhikari_node.dylib npm/hikari-node.node  # .dll/.so per OS
node npm/test.mjs

Requires Rust 1.78+. No system dependencies — everything is pure Rust except the optional system CJK fallback fonts at runtime.
