OG images, SVG, GIF, and PDFs from layout trees.
No browser.

Hikari is a pure-Rust render engine: one JSON-serializable node tree in, PNG / SVG / GIF / APNG / WebP / PDF out — on servers, in Node.js, and in the browser via WebAssembly. Upstream-only dependencies, offline everything.

Try it live — runs 100% in your browser Install in 60 seconds

cargo add hikari-rs
# or: npm i @hikari-rs/node
