# Hikari Commercial License (Pro / Scale) — summary

This is a human-readable summary. The full terms ship with purchased keys.

1. **Grant.** One key covers unlimited renders on self-hosted infrastructure
   for the licensed team or company, depending on tier.
2. **Prohibited.** Reselling keys, publishing the private signing key, or
   removing license checks from redistributed binaries.
3. **Scale tier.** Adds redistribution rights for closed-source products and
   embedding in SaaS offerings. Contact for terms.
4. **No warranty.** Pro modules ship with the same "as is" warranty as the
   open core; SLAs apply only to the Scale SaaS API.
5. **Termination.** Expired or refunded keys stop verifying; previously
   rendered output remains yours forever.

The open core (`hikari-core`, `hikari-raster`, `hikari-svg`, `hikari`)
remains MIT OR Apache-2.0 regardless of Pro status.
